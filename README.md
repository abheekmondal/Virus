# Virus
This repository is where I keep the viruses I created and am currently testing.

1. lock.bat =  continiously keeps locking the screen for an infinite amount of time.
2. scan = Quickly scan a subnet for alive hosts.
3. credharve = Dump saved Wi-Fi passwords.
4. dataexfil = Upload files to an FTP server (replace credentials).
5. dbdumpSAM = Dump SAM hashes (requires admin privileges).
6. defdis = Temporarily disable Defender (for testing bypasses).
7. DLLhijack = Inject a DLL into a process (replace PROCESS_NAME).
8. misconcheck = Identify unquoted service paths, writable directories, etc. 
9. passpraySMB = Spray passwords against SMB (replace USERLIST/PASSWORDS).
10. revsh = Connect back to a listener (replace ATTACKER_IP and PORT).
